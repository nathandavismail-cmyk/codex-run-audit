# Support

For installation and common errors, start with [the installation guide](docs/install.md).
For export formats and version evidence, see [compatibility](docs/compatibility.md).
For measurements and unknowns, see [accounting](docs/accounting.md).

Repository members can use the existing bug and feature templates. Once public,
the same templates are available to external users. Include Node/OS/tool versions,
a minimal synthetic reproduction and independently expected behavior. Do not
upload raw transcripts or credentials. Support is best-effort; response times
are not guaranteed. Developer feedback is welcome but is not a release gate.

Security issues follow [SECURITY.md](SECURITY.md), not ordinary public issues.
The private vulnerability-reporting form is prepared, with activation still part
of authorized public launch. See [versioning](docs/versioning.md) for 1.x scope.
