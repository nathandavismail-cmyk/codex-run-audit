# Codex Run Audit 1.0.0 — release notes

Distribution: GitHub release archives. Not published to npm.

Codex Run Audit is an offline CLI for inspecting one Codex execution export.
Generate a readable HTML report and structured JSON with token accounting,
recorded failures and repeated commands, per-turn measurements, event order,
and evidence-specific next steps. Compare two reports without assuming that
lower token usage means better work.

## Included

- Explicit `codex exec --json` import; bounded input and conservative unknowns.
- Self-contained HTML without scripts or external assets; raw transcript content
  is omitted. Source hashes and counts can still be sensitive.
- `analyze`, `compare`, `demo` and optional browser opening with a safe fallback.
- Zero runtime dependencies; Node.js 24+ required, Node 24 tested.
- Documented 1.x command and JSON compatibility contract, preserving v1 schemas.
- Original synthetic examples and reproducible diagnosis-fixture checks.

## Compatibility and evidence

macOS arm64 and Ubuntu installation and removal have been tested. Chromium,
WebKit and Firefox desktop/mobile report checks are recorded in validation.
Mock-provider native Codex success/failure exports and one prior real no-tool
smoke test provide limited native evidence, not a broad certification.

Native command execution is still host-sandbox-blocked in verification; actual
Safari launching is unverified. Windows, raw history rollouts, account-wide
usage, billing costs and independent task success are not supported claims.
No productivity improvement or token savings benchmark is claimed.

## Install and report issues

Use the repository installation guide and the source or package archive attached
to this release. There is no npm installation command until
npm publication has actually succeeded. Existing reports survive uninstall.

For non-sensitive bugs, provide a minimal synthetic reproduction. Security
reports must use the verified private reporting route in SECURITY.md. Do not attach private transcripts.
